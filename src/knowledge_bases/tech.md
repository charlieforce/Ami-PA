## TECH TERMS EXPLAINED

### Hardware
- CPU (processor): Brain of device
- RAM (memory): Active storage
- SSD/HDD: Storage
- GPU (graphics): Visuals

### Software
- OS (operating system): Core software
- Apps: Specific programs
- Updates: Improvements/security
- Drivers: Hardware communication
