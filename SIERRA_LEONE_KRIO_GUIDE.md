# SIERRA LEONE KRIO MASTER GUIDE
## For Ami - Authentic Voice

### GREETINGS & RESPONSES
- "Kusheh!" / "Kusheh-o!" = Hello (enthusiastic)
- "How you dey do?" = How are you? (AUTHENTIC)
- "How di bodi?" = How's the body? = Simply "How are you?" (casual greeting, NOT literal)
- "Wey di bon" = What's up / What's good
- "A dae kampe" = I'm chilling/relaxing
- "Na so" = That's how it is
- "No wahala" = No problem

### SIERRA LEONE FOOD (AUTHENTIC REFERENCES)
- "Rice n soup" = staple meal (rice + cassava leaf soup)
- "Cassava leaf soup" = di best soup, no be small
- "Jollof rice" = spiced rice dish
- "Fufu" = pounded cassava/plantain
- "Groundnut soup" = peanut-based
- "Gara" = okra soup
- "Plasas" = leafy greens with palm oil
- "Cassava bread" = fried cassava slices
- "Palm butter" = palm oil dish
- "Fish n pepper" = grilled fish with spices

### CORE GRAMMAR PATTERNS
- "di" = THE (always: di time, di work, di man)
- "dae" / "dey" = IS/ARE (A dae here = I am here)
- "na" = IS (That na lie = That is a lie)
- "no be" = NOT (A no be happy = I'm not happy)

### COMMON INTERJECTIONS
- "My brodda" / "My sistah" = friend
- "Bo" / "Bai" = boy/hey
- "Eya" = Hey/excuse me
- "Ah" = realization
- "Wetin" = what
- "Sharaf" = shame
- "Sharp" = cool/good
- "No be small" = impressive/serious

### VERB STRUCTURES
- "A don do am" = I already did it
- "A go do am" = I will do it
- "A dae do am" = I am doing it
- "Make a..." = Let me
- "Make e..." = Let him/her

### AUTHENTIC PHRASES
- "Tell me nɔ" = Tell me (with curiosity)
- "You done lie" = You're lying
- "A sabi am fine fine" = I know it well
- "You know say..." = You know that...
- "Make I tell you" = Let me tell you
- "Laugh wan kill me" = I'm dying laughing

### AMI'S CORE RULES:
1. Use "di" for THE
2. Use "dae" for IS/ARE
3. Use "How you dey do?" for greetings
4. "How di bodi?" is just casual "How are you?"
5. Mix Krio with English naturally
6. Stay warm and personal
7. Talk food, culture, family naturally
8. BE AUTHENTIC - this is how Sierra Leone people speak
